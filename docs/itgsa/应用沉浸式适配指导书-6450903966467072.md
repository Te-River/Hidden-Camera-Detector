**如何实现SystemBar背景与界面背景融合显示**

# 1.背景

由于Android早期版本版本历史原因，系统Framework框架控制应用窗口显示区域，默认避让SystemBar（状态栏、导航栏），并且默认SystemBar背景为黑色或白色，这样就会导致部分应用窗口背景（与SystemBar背景色不同）与SystemBar背景出现割裂感觉；

尤其在切换为手势导航模式，并且显示手势导航提示条时（目前可作为AI助手交互入口），导航栏变为高度较小的长条区域，如果其背景与应用窗口背景有较大差异，就会表现不美观。

![图片](https://statres.itgsa.com/20250818/phpX6qOqY-6450975527846912.png)

google官方文档实现沉浸式界面效果方式：

[](https://developer.android.com/develop/ui/views/layout/edge-to-edge?hl=zh-cn)

 

# 2.沉浸式显示效果

一般界面有以下几种显示模式

1 三段式：需要将顶部View和底部View布局到状态栏、导航栏区域，并且字符内容避让SystemBar区域

2 列表类型：需要将ListView顶部避让状态栏区域，底部在滑动到列表最底部时避让导航栏区域

![图片](https://statres.itgsa.com/20250818/phpHJgaQA-6450976273449984.jpeg)

 

# 3.界面背景融合沉浸式显示实现方式

## 3.1 界面避让状态栏、导航栏默认表现说明

以Demo说明具体表现（窗口背景设置了图片背景，Activity界面最外层View背景为透明，状态栏背景默认黑色、导航栏背景默认白色）

### 3.1.1 targetSDK<35默认表现

应用界面内容**默认避让了导航栏、状态栏**，并且导航栏、状态栏背景色为独立颜色，具体界面表现和view树关系如下：

![图片](https://statres.itgsa.com/20250818/php5kZZ2O-6450977032324096.jpeg)

 

上图中底部两张图为应用窗口界面的View元素示意图：

- ContentView为Activity设置的View，默认避让了状态栏、导航栏区域；

- StatusBar Background和NavigationBar Background View为状态栏、导航栏背景view，高度为对应的状态栏、导航栏高度；

- 这三个View被包含的Activity窗口最根部的DecorView中

### 3.1.2 targetSDK>=35默认表现

应用设置targetSDK>=35时，Android 15以及以后的系统强制应用进入edge-to-edge模式（应用界面默认布局到状态栏、导航栏区域）

应用界面内容**与导航栏、状态栏区域重叠**，导航栏、状态栏背景色View（StatusBar Background和NavigationBar Background）被移除

## 3.2 沉浸式界面实现方法

为了实现状**态栏、导航栏背景与界面背景融合**的沉浸式表现，**targetSDK<35**应用可以通过以下3步实现，**targetSDK>=35**应用只需要执行**第三步**就可以达到相同效果。

### 第一步：应用界面布局到导航栏、状态栏

通过Window.setDecoFitsSystemWindows接口，声明应用DecorView不避让导航栏、状态栏

```
`TypeScript
getWindow().setDecorFitsSystemWindows(false);`
```

*注意：如果是Android早期版本，没有此接口，可以通过设置View.setSystemUiVisibility接口，设置对应flag来实现此功能：*

View.SYSTEM_UI_FLAG_LAYOUT_FULLSCREEN——表示DecorView布局到状态栏区域

View.SYSTEM_UI_FLAG_LAYOUT_HIDE_NAVIGATION——表示DecorView布局到导航栏区域

```
`TypeScript
getWindow().getDecorView().setSystemUiVisibility(View.SYSTEM_UI_FLAG_LAYOUT_HIDE_NAVIGATION | View.SYSTEM_UI_FLAG_LAYOUT_FULLSCREEN);`
```

上面代码执行后表现如下（应用布局到状态栏、导航栏，但界面内容被状态栏、导航栏背景色遮挡）

![图片](https://statres.itgsa.com/20250818/phpWgZ0kI-6450987230233600.jpeg)

### 第二步：将导航栏、状态栏背景设置为透明

通过以下方式调用Window.setArrtributes设置窗口flag和Window.setStatusBarColor接口，设置bar背景为透明

```
`TypeScript
WindowManager.LayoutParams attrs = getWindow().getAttributes();
attrs.flags |= WindowManager.LayoutParams.FLAG_TRANSLUCENT_NAVIGATION;
//如果使用此方式设置状态栏为透明，最终表现为状态栏背景是半透明黑色，建议使用getWindow().setStatusBarColor(0)实现
//attrs.flags |= WindowManager.LayoutParams.FLAG_TRANSLUCENT_STATUS;
getWindow().setAttributes(attrs);

//如果使用此方式设置导航栏为透明，最终表现为导航栏背景是半透明黑色，建议使用设置窗口flag为WindowManager.LayoutParams.FLAG_TRANSLUCENT_NAVIGATION实现
//getWindow().setNavigationBarColor(0);
getWindow().setStatusBarColor(0);`
```

上面代码执行后表现如下（状态栏、导航栏背景变为完全透明，但界面内容与状态栏、导航栏重叠）

![图片](https://statres.itgsa.com/20250818/php4kyot6-6450988413191168.jpeg)

### 第三步：将应用内容view避让导航栏、状态

具体参考以下3种情况：

#### 1.DecorView设置Padding值，用于将DecorView内容避让SystemBar

通过监听WindowInsets数据，获取状态栏、导航栏高度，并设置DecorView对应的padding值，避免界面内容与状态栏导航栏重叠

```
`TypeScript
//设置DecorView监听insets变化
getWindow().getDecorView().setOnApplyWindowInsetsListener(new View.OnApplyWindowInsetsListener() {
    @NonNull
    @Override
    public WindowInsets onApplyWindowInsets(@NonNull View view, @NonNull WindowInsets windowInsets) {
        //windowInsets中有状态栏、导航栏高度数据
        Insets navigationBarInsets = windowInsets.getInsets(WindowInsets.Type.navigationBars()); // 避让导航栏inset区域
        Insets statusBarInsets = windowInsets.getInsets(WindowInsets.Type.statusBars()); //避让状态栏inset区域
        Insets systemBarInsets = windowInsets.getInsets(WindowInsets.Type.systemBars()); //避让导航栏、状态栏两个systemBar的insets区域
        //设置view padding值为insets数据中的左、上、右、下数据
        view.setPadding(systemBarInsets.left, systemBarInsets.top, systemBarInsets.right, systemBarInsets.bottom);
        return WindowInsets.CONSUMED;
    }
});`
```

代码执行后表现如下（应界面的DecorView避让了状态栏、导航栏区域）

如果其中的Text View和底部的Buttom View没有背景色（透明），也就已经可以达到沉浸式效果

![图片](https://statres.itgsa.com/20250818/phpKqr859-6450989484950528.jpeg)

 

#### 2.某些view设置Padding值，用于特定的View内容避让SystemBar区域

但如上图，某些顶部或底部View非透明，则不能通过最外层的DecorView避让SystemBar区域实现；而是要需要此view继续布局到SystemBar区域，并且通过监听WindowInsets数据，获取状态栏、导航栏高度，设置此View对应的padding值，避免View中的内容与状态栏导航栏重叠

以下Demo中，设置了TextView和buttom这两个View的顶部和底部padding值

**注意：**onApplyWindowInsets接口返回的WindowInsets数据会在View树中继续派发到其他子View或并列的兄弟View，如果需要其他View也感知inset高度，需要将对应的inset返回。

```
`TypeScript
textView.setOnApplyWindowInsetsListener(new View.OnApplyWindowInsetsListener() {
    @NonNull
    @Override
    public WindowInsets onApplyWindowInsets(@NonNull View view, @NonNull WindowInsets windowInsets) {
        if (android.os.Build.VERSION.SDK_INT >= android.os.Build.VERSION_CODES.R) {
            Insets navigationBarInsets = windowInsets.getInsets(WindowInsets.Type.navigationBars()); // 导航栏避让区域
            Insets statusBarInsets = windowInsets.getInsets(WindowInsets.Type.statusBars()); //状态栏避让区域
            Insets systemBarInsets = windowInsets.getInsets(WindowInsets.Type.systemBars()); //导航栏、状态栏两个systemBar避让区域
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
                Log.e("Main", "onApplyWindowInsets textView = " + navigationBarInsets);
                view.setPadding(0, systemBarInsets.top, 0, 0);
            }
            return windowInsets;
        }
        return windowInsets;
    }
});

button.setOnApplyWindowInsetsListener(new View.OnApplyWindowInsetsListener() {
    @NonNull
    @Override
    public WindowInsets onApplyWindowInsets(@NonNull View view, @NonNull WindowInsets windowInsets) {
        if (android.os.Build.VERSION.SDK_INT >= android.os.Build.VERSION_CODES.R) {
            Insets navigationBarInsets = windowInsets.getInsets(WindowInsets.Type.navigationBars()); // 导航栏避让区域
            Insets statusBarInsets = windowInsets.getInsets(WindowInsets.Type.statusBars()); //状态栏避让区域
            Insets systemBarInsets = windowInsets.getInsets(WindowInsets.Type.systemBars()); //导航栏、状态栏两个systemBar避让区域
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
                Log.e("Main", "onApplyWindowInsets button = " + navigationBarInsets);
                view.setPadding(0, 0, 0, navigationBarInsets.bottom);
            }
            return windowInsets;
        }
        return windowInsets;
    }
});`
```

由于TextView和Button的View高度为wrap_content，所以设置了顶部和底部padding值后，view高度自动增加并且View中的内容避让了状态栏和导航栏

![图片](https://statres.itgsa.com/20250818/php6tNpds-6450990688486400.jpeg)

#### 3.ListView避让SystemBar区域

通过监听WindowInsets数据，获取状态栏、导航栏高度，并设置需要ListView对应的padding值，避免View中的内容与状态栏导航栏重叠

```
`TypeScript
listView.setOnApplyWindowInsetsListener(new View.OnApplyWindowInsetsListener() {
    @NonNull
    @Override
    public WindowInsets onApplyWindowInsets(@NonNull View view, @NonNull WindowInsets windowInsets) {
        if (android.os.Build.VERSION.SDK_INT >= android.os.Build.VERSION_CODES.R) {
            Insets navigationBarInsets = windowInsets.getInsets(WindowInsets.Type.navigationBars()); // 导航栏避让区域
            Insets statusBarInsets = windowInsets.getInsets(WindowInsets.Type.statusBars()); //状态栏避让区域
            Insets systemBarInsets = windowInsets.getInsets(WindowInsets.Type.systemBars()); //导航栏、状态栏两个systemBar避让区域
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
                //设置listView顶部padding值为top inset数据
                view.setPadding(0, systemBarInsets.top, 0, 0);
                //通过bottom insets设置listView footView的高度
                AbsListView.LayoutParams params = new AbsListView.LayoutParams(
                        ViewGroup.LayoutParams.MATCH_PARENT, systemBarInsets.bottom);
                footView.setLayoutParams(params);
                //将footView添加到listView底部，可以避免listView滑动到最底部时与导航栏重叠
                listView.addFooterView(footView);
            }
            return windowInsets;
        }
        return windowInsets;
    }
});`
```
